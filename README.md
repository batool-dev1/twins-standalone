# 🏛️ Minimalist Interior Architecture Studio

A modern, elegant, and fully responsive web application designed for a luxury interior architecture studio. Built with clean HTML5, Tailwind CSS, and vanilla JavaScript, emphasizing a minimalist aesthetic and seamless user experience.

---

## ✨ Features

- **Responsive Design:** Crafted to look stunning and perform smoothly across all devices (desktops, tablets, and mobile phones).
- **Interactive Portfolio Filter:** Real-time category filtering (Residential vs. Commercial) built with native JavaScript.
- **Minimalist Aesthetic:** Clean typography (`Tajawal`), neutral color palette, and spacious layouts reflecting high-end architectural design.
- **Client Contact Form:** Integrated layout for inquiries and consultation bookings.

---

## 🛠️ Tech Stack

- **HTML5** & **Tailwind CSS (CDN)** for rapid, lightweight, and responsive styling.
- **Vanilla JavaScript (ES6+)** for dynamic filtering and interactive UI elements.
- **Google Fonts** (`Tajawal`) for clean Arabic typography.
- **GitHub Pages** for fast, reliable, and live static hosting.
